# 🏍️ TripHisaab Android App

This directory contains the complete native Android source code for **TripHisaab** (Trip Budget).

Please refer to the [Root README.md](../README.md) for full architecture details, processing pipeline diagrams, setup guides, and WhatsApp syntax examples.

## Quickstart in Android Studio

1. Open Android Studio.
2. Select **Open** and select this `triphisaab` directory.
3. Allow Gradle to sync dependencies.
4. Set up an Android device or emulator running Android 10+ (API 29+).
5. Build and install:
   ```bash
   ./gradlew assembleDebug installDebug
   ```
6. Complete the setup wizard inside the app to grant Notification Access, generate a pairing code, and link your personal WhatsApp to your WhatsApp Business number.
